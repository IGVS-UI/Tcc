Como funciona o Google Maps 360°?

O visual imersivo combina captura panorâmica, costura de imagens e navegação interativa para aproximar o usuário de cada lugar.

Captura das imagens

O Google usa câmeras especiais de 360° para registrar fotos panorâmicas dos locais.

Criacao do ambiente navegavel

As imagens são conectadas em pontos de navegação para criar uma experiência fluida e interativa.

Exploração pelo usuário

O visitante gira a cena, troca destinos e percorre lugares famosos como se estivesse la.
