Como funciona o Google Maps 360°?

O visual imersivo combina captura panoramica, costura de imagens e navegacao interativa para aproximar o usuario de cada lugar.

Captura das imagens

O Google usa cameras especiais de 360° para registrar fotos panoramicas dos locais.

Criacao do ambiente navegavel

As imagens sao conectadas em pontos de navegacao para criar uma experiencia fluida e interativa.

Exploracao pelo usuario

O visitante gira a cena, troca destinos e percorre lugares famosos como se estivesse la.
